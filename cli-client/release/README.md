** Windows Users: **

1. Download the following 2 files from the current GitHub Directory: 
   - install-windows.ps1
   - se2537.exe
2. Right-click install-windows.ps1 → Run with PowerShell or open PowerShell -> Run  ./PATHTOTHEINSTALLER/install-windows.ps1
3. See this:

=================================
  se2537 Installer
=================================

This will install se2537 to:
  C:\Users\John\AppData\Local\Programs\se2537

and add it to your PATH so you can use it anywhere.

Continue? (Y/N): y

Installing...

=================================
  Installation Successful!
=================================

You can now use se2537 from anywhere!

Try it now:
  se2537 healthcheck


** macOS/Linux Users: **

1. Download the following 2 files from the current GitHub Directory: 
   - install-macos.sh  on macos (or install-linux.sh on linux)
   - se2537-macos-arm or se2537-macos-intel on macos (or se2537-linux on linux)
2. Open Terminal
3. Run: bash install-macos.sh on macos (or install-linux.sh on linux)
4. Press y
5. See success message like above
6. Type for confirmation: se2537 healthcheck
